# Piano samples

Salamander Grand Piano V3 by Alexander Holm, licensed CC BY 3.0 (see `LICENSE-CC-BY-3.0.txt`).
Source: https://archive.org/details/SalamanderGrandPianoV3, via https://github.com/sfzinstruments/SalamanderGrandPiano

Changes: seven of the sixteen velocity layers (v2, v5, v7, v9, v11, v13, v15), note samples cut to 12 seconds with a 1.5-second fade,
key-release and pedal samples kept, all converted from 48 kHz FLAC to 44.1 kHz MP3 (`Ds` = D♯, `Fs` = F♯).
